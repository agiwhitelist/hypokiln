# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) verbatim.

Read it here: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Report unacceptable behavior to the maintainers via a private
[security advisory](https://github.com/agiwhitelist/hypokiln/security/advisories/new)
or by email to the address listed in `SECURITY.md`. Reports are confidential.
