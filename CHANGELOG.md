## [0.1.1] - 2026-05-12

### Added
- Windows installer (`install.ps1`) — one-line bootstrap via `irm ... | iex`.
- Auto-clone bootstrap in `install.sh` so `curl ... | bash` works outside a checkout.
- Docker image + `docker-compose.yml` for the API + Next.js dashboard.
- Devcontainer / GitHub Codespaces configuration.
- GitHub release workflow: tags `v*` publish to PyPI (Trusted Publishing, bound to the `pypi` environment) and GHCR (multi-arch via QEMU/Buildx) and cut a GitHub Release with autogenerated notes.
- Issue templates (bug / feature), PR template, Dependabot (pip + npm + actions + docker), FUNDING, Code of Conduct.
- 1280×640 social preview image (`docs/social-preview.png`) + source SVG.
- `web/package-lock.json` (was missing — `actions/setup-node` cache step now resolves).

### Changed
- README: real CI badge, per-OS one-liners (`curl | bash`, `irm | iex`, `docker compose`, Codespaces).
- `pyproject.toml`: switched to `[tool.setuptools.packages.find]` so subpackages (`agents/*`, `control/routers/*`, `hypokiln/runners/*`) ship in the wheel. Added `readme`, `authors`, `classifiers`, `[project.urls]` so the PyPI page renders cleanly (`twine check` PASSED, no warnings).

### Fixed
- Ruff: autofixed 12 F401/F541 (unused imports, extraneous f-string prefixes) across `hypokiln/`, `control/routers/`, `tests/`.
- CI: dropped `npm run lint` — `next lint` hung on an interactive ESLint setup wizard because no ESLint config / deps ship; typecheck + build remain the binding gates.

## [0.1.0] - 2026-05-12

### Added
- First public release.
- Six-stage kiln: Trend Radar → Pain Extractor → Hypothesis Generator → Kill Filter → Market Snapshot → Selection + Architecture + Pre-flight.
- Critique loop on stages 1, 3, 5: author CLI session ↔ deterministic gate ↔ Market-Skeptic critic.
- Four in-repo skill packs: `capability-radar`, `anti-patterns`, `architecture-and-virality`, `domain-patterns`.
- `kiln` CLI (`build`, `resume`, `status`, `capability-scan`, `skills`, `*-audit`).
- FastAPI control plane on `:8765` + Next.js dashboard on `:3000`.
- Bring-your-own coding CLI: codex / claude / gemini.
